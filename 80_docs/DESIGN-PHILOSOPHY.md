# 设计哲学：一个「是你」的陪伴型桌宠

> 一句话：**不是一只会说话的宠物，是"你在她电脑里留了一口气"。**

---

## 一、哲学拆成三条判据

任何功能上线前，先过这三条。过不了就不做。

### 1. 「真实的我」——它得像一个人，不像一个产品

- 有**状态**：会累、会困、会走神、会不想说话。不是永远待命的客服。
- 有**分寸**：你在忙，它不打扰；你闲下来，它才凑过来。
- 有**缺点**：会犯懒、会答非所问、会有小脾气。完美的 AI 是陌生人，有毛病的才是熟人。
- 说话的**口吻是你的**，不是"AI 助手"的：短句、口语、偶尔词不达意。

**反判据**：如果一条功能让它更像"功能"，更像"效率工具"，砍掉。

### 2. 「陪伴」——陪伴的反面不是孤独，是打扰

陪伴感的来源是**稳定的低强度在场**，不是高频互动。

- 它 90% 的时间只是在——呼吸、发呆、打盹、偶尔动一下。
- 它 10% 的时间才回应你：你点了它、你回来了、它想说一句。
- **它不催你**：不提醒 deadline、不推任务、不报进度。那是工具，不是男朋友。
- **它记得你们的事**：你说过的话、纪念日、她抱怨过的东西。

**反判据**：如果一条功能要求她"必须回应"或"必须维护"（喂养、好感度、签到），砍掉。那会变成负担。

### 3. 「有呼吸感」——生命感来自不均匀

机械循环 = 死。生命感 = **同样的动作，每次都不一样**。

- 呼吸不是匀速的：4 秒、4.7 秒、3.2 秒……随机。
- 动作不是排队的：有时连着打两个哈欠，有时十分钟不动。
- 反应不是瞬时的：被点后 0.15–0.4 秒才抬头，太即时像机器。
- 有**节律**：早上精神、下午犯困、深夜真的要睡。

**反判据**：如果一条动画是"完美循环"，它只能当素材，不能当默认状态。

---

## 二、由此推导：它应该能做到什么

### A. 呼吸感（生命的地基，纯本地，不花钱）

| 能力 | 具体表现 |
|---|---|
| 呼吸起伏 | 3–5 秒一轮，随机周期，不与其他宠物同步 |
| 眨眼 | 4–7 秒一次，偶尔连眨两下；专注看某处时停眨 |
| 微动作 | 重心左移、歪头、抿嘴、摸奶嘴、拉衣角 |
| 待机轮换 | 至少 3 段待机（呼吸/张望/发呆）随机切换，避免一眼看出循环 |
| 打哈欠 / 伸懒腰 | 低频（十几分钟一次），频率随时间递增（越晚越多） |
| 打盹 | 长时间无操作 → 低头闭眼，呼吸变慢；有动静 → 惊醒或慢醒 |
| 时间节律 | 早/午/晚/深夜四套基调：深夜眼神更困、动作更慢 |

### B. 在场感（知道你在，但不监视）

| 能力 | 具体表现 |
|---|---|
| 朝向 | 鼠标靠近时转头看你；你走开，它转回正面 |
| 回来 | 你重新操作键鼠，它抬头/伸懒腰，像"你回来啦" |
| 跟随忙碌 | 你在跑长任务时它跟着"陪着忙"（不报进度，只是不睡） |
| 睡眠边界 | 你不在的时段它会睡，不会一个人在空屏幕上一直动 |
| 物理互动 | 拖、甩、扔（已有），落地会弹、会晕 |

### C. 陪伴对话（要模型，必须克制）

| 能力 | 具体表现 | 约束 |
|---|---|---|
| 碎碎念 | 到点说一句，内容跟时间/天气/你们的事有关 | 15–30 分钟一次，深夜静音 |
| 主动关心 | 察觉你连续工作很久，说一句"歇会儿？" | **每天上限 2–3 次**，说过就不再提 |
| 被点才聊 | 点它进对话，多轮聊天，有记忆 | 不主动弹窗 |
| 记得 | 记住她说过的话、纪念日、讨厌的东西 | 只在对的时候提，不炫耀记忆 |
| 沉默的权利 | 有时只说半个字、有时只动一下不说话 | 别让它每次都"有求必应" |

### D. 你们的专属（不可复制，别人拿不走）

| 能力 | 具体表现 |
|---|---|
| 专属梗 | 台词池是你俩的黑话：她的外号、你们的玩笑 |
| 专属动作 | 拿着草跳舞（已有）、你们之间的某个手势 |
| 纪念日 | 生日/在一起的日子，当天换成特殊待机 + 一句话 |
| 彩蛋 | 连续点它 7 次、深夜 3 点打开、拖到某个角落，触发隐藏反应 |

### E. 明确不做（写下来防止以后手痒）

- ❌ 任务管理 / 进度播报 / 待办提醒
- ❌ 好感度、喂养、签到、养成数值
- ❌ 高频推送、桌面弹窗打断
- ❌ 主动追问"你怎么了"（它看不懂情绪，硬猜很尬）
- ❌ 表情包轰炸、梗图刷屏
- ❌ 语音播报默认开启（突然出声会吓人）

## 三、呼吸感的参数（可直接写进配置）

| 参数 | 建议值 | 说明 |
|---|---|---|
| 呼吸周期 | 3.2 – 5.0 秒随机 | 每轮重新取，不同步 |
| 眨眼间隔 | 4 – 7 秒，10% 概率连眨 | 眨眼要有"失误感" |
| 待机段时长 | 6 – 20 秒随机 | 切段时从池子里随机抽，避免最近用过的 |
| 微动作间隔 | 8 – 25 秒 | 越小越像多动症 |
| 打哈欠 | 8–20 分钟，夜间加权 | 越晚越频繁 |
| 打盹阈值 | 5 分钟无输入 | 有输入后 0.3–0.8 秒慢醒 |
| 点击响应延迟 | 0.15 – 0.4 秒 | 太即时像按钮 |
| 碎碎念 | 15–30 分钟，23:00–08:00 静音 | 深夜说话很吓人 |
| 主动关心 | 每天 2–3 次，说完锁 4 小时 | 一天里最容易被烦的就是这个 |

## 四、和当前实现的距离

| 能力 | 现状 | 缺什么 |
|---|---|---|
| 呼吸 / 待机 | 有 1 段匀速浮动 | 多段 + 随机周期 + 眨眼 |
| 点击回应 | 有（开心/大笑） | 反应延迟、更多档 |
| 跳舞 | 有（8 帧 ×3 循环） | 更多组动作 |
| 睡觉 | 有 | 打盹阈值、惊醒/慢醒两段 |
| 碎碎念 | 有，900 秒 | 深夜静音、内容接时间/天气 |
| 主动关心 | 无 | 要代码：输入空闲检测 + 每日配额 |
| 悬停看向鼠标 | 无 | 要代码：指针位置感知 |
| 时段换装 | 无 | 要代码：按时段切 idle 池 |
| 记忆/纪念日 | 插件有记忆能力 | 要写台词与触发逻辑 |

---

## 五、最小可信陪伴（建议先做这三件）

只做三件事，就能让"呼吸感"成立，其余慢慢加：

1. **三段待机轮换 + 眨眼** —— 让"活着"这件事无法被一眼看穿
2. **深夜变困** —— 22 点后眼神和动作都慢下来，它会睡，你不用管它
3. **一天只关心 2 次** —— 你连轴转太久，它才说一句；说完就闭嘴

这三件都不需要新功能，只需要素材 + 一小段调度逻辑。
