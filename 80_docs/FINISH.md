# 人设、面板与参数（收尾补充）

## 八、人设与语气

贝草兰是**男友人设**：温柔、鼓励为主，会叫你「小宝贝 / 小宝宝 / honey」。

- 通用台词：`小宝贝，喝口水吧`、`别急，慢慢来`、`我一直在这儿`
- 看你在干什么再说：画图 → `又要画图啦，真厉害`；报错 → `别急，我陪你想`；
  论文 → `写得真好，慢慢来`；代码 → `小宝贝写得真快`；累了 → `去睡吧，我守着`
- 点它一下：`小宝贝在呢`、`摸摸头`、`我一直陪着你`
- 护眼提醒：`小宝贝，歇一会儿眼睛吧～`

全部**零 token**（本地台词池 + 关键词），不联网、不调用模型。

## 九、设置面板与宠物大小的关系

桌面面板（dsh-pet 的「桌宠配置」）里，**只有「大小 size」会影响贝草兰**：

| 面板里的 size | 宠物高度 |
|---|---|
| 500（默认） | 83px |
| 700 | 117px |

换算：`displayHeight = size / 6`，钳制在 40–220。
如果 `~/.dsh/dsh-sitter/config.json` 里自己写了 `displayHeight`，以你的为准。

面板里的其它项（语音、物理、动画权重、余额气泡等）属于 dsh-pet 的桌面透明窗，
**对贝草兰不起作用**——我们不用那套系统。

## 十、贝草兰自己的参数

改 `~/.dsh/dsh-sitter/config.json`（改完 5 秒内生效）：

```json
{
  "displayHeight": 83,
  "timeline": { "sleepMs": 30000 },
  "night": { "from": 23, "to": 7 },
  "outfits": { "force": null },
  "break": { "enabled": true, "workMs": 2400000 },
  "escalate": { "enabled": true, "idleMs": 180000, "stepMs": 10000 },
  "chat": { "enabled": true, "intervalMs": 75000 }
}
```
