# 贝草兰 · 交付说明

一个坐在输入框上的像素小家伙。会陪你写东西、提醒你休息、晚上换睡衣、困了会打盹。

---

## 一、装到哪里

插件本体是 `dsh-sitter/` 目录，共 6 个文件：

```
dsh-sitter/
├─ package.json        # 插件清单
├─ cordis.patch.yml    # 挂载声明
├─ index.js            # 宿主：统计/状态服务（localhost:43717）
├─ client.js           # 页面端：宠物本体
├─ icon.png            # 插件列表图标
└─ README.md
```

### 安装（推荐）

1. 把整个 `dsh-sitter` 目录放到一个**固定的本地路径**，例如 `D:\pet\dsh-sitter`。
   > 不要放网盘/同步目录——同步中途可能读到半个文件。
2. 打开 DSH → 设置 → 插件 → 安装（"从本地目录安装"），选择该目录。
3. **刷新一次页面**（Ctrl+R）。桌面上的宠物会出现。

### 安装（手工，万一上面的入口找不到）

在 `C:\Users\<你>\.dsh\profiles\desktop\package.json` 的依赖里加：

```json
"@local/dsh-sitter": "file:D:/pet/dsh-sitter"
```

并在 `dsh.profile.bundles` 数组里加 `"@local/dsh-sitter"`，然后在 profile 目录执行 `pnpm install`，重启 DSH。

## 二、它会做什么

| 场景 | 表现 |
|---|---|
| 刚打开 | 盖着小恐龙被子睡一会儿（约 30 秒），然后进试衣间换装，坐下待机 |
| 你打字 | 掏出台迷你笔记本一起敲，头顶冒思考云 |
| 助手干活 | 同样掏出笔记本陪着你一起忙 |
| 鼠标停它身上 | 弹出小卡片：今日已用 token / 今日使用时长 / 今天被提醒几次 |
| 点它一下 | 弹一下 + 说一句话 |
| **23:00–07:00** | 自动换成浅蓝睡衣 |
| 白天 | 按月份换季（春夏秋冬四套） |
| 连续工作 **40 分钟** | 放下电脑，在输入框上来回跑 3 趟，头顶写「该休息一会儿啦～」，跑完自己回去坐 |
| 长时间没人管 | 每 3 分钟放大一倍，直到占满屏幕；点它 → 「要认真学习，知道吗？」→ 点「知道了」才复原 |
| 每隔一分多钟 | 自己咕哝一句（按时段挑，深夜会闭嘴） |
| 整点 | 报一句「X 点啦」 |

## 三、怎么改

所有参数在 `C:\Users\<你>\.dsh\dsh-sitter\config.json`（没有就自己建），**改完 5 秒内生效，不用重启**。

常改的几个：

```json
{
  "displayHeight": 83,
  "timeline": { "sleepMs": 30000 },
  "night": { "from": 23, "to": 7 },
  "outfits": { "force": null },
  "break": { "workMs": 2400000 },
  "escalate": { "idleMs": 180000, "stepMs": 10000 },
  "chat": { "intervalMs": 75000 }
}
```

- `displayHeight`：宠物大小（默认 83）
- `sleepMs`：开场睡多久（0 = 不睡）
- `outfits.force`：`null` 自动 / `0`冬 `1`秋 `2`春 `3`夏 / `"pajama"` 睡衣
- `break.workMs`：多久提醒休息（默认 40 分钟）
- `escalate.idleMs`：多久没人管开始放大（默认 3 分钟）
- `chat.intervalMs`：多久咕哝一句（默认 75 秒）

想让它彻底安静：`"chat": {"enabled": false}`。
想让它别长太大：`"escalate": {"enabled": false}`。

## 四、出问题怎么办

| 现象 | 先看 |
|---|---|
| 宠物不见了 | 刷新页面（Ctrl+R）；再不行看 `~/.dsh/dsh-sitter/client-error.log` |
| 贴不到输入框 | 换会话或刷新；插件会自动重试 30 秒 |
| 悬停卡没数字 | 确认 43717 端口没被占；看 `~/.dsh/dsh-sitter/port.txt` |
| 改了配置没反应 | 等 5 秒（客户端每 5 秒拉一次）；确认 JSON 没写错 |
| 插件管理器里报错 | 看 `~/.dsh/dsh-sitter/server-error.log` |

## 五、已知限制

- 需要 DSH 的 Web 页面环境；纯 CLI 模式没有宠物。
- 统计读的是会话日志（`~/.dsh/sessions/**/*.zstd`），DSH 若改存储格式，数字会显示 0（不会崩）。
- 端口默认 43717，被占时自动尝试 43718–43720。

## 六、重要：更新后必须刷新页面

DSH 的**页面端插件模块只在页面加载时装载一次**。开关插件只会重启宿主（统计/状态服务），
**不会**把新的 client.js 推到已经打开的页面里。

现象：改了宠物行为，插件管理器里显示已启用，但页面上的宠物还是旧的（甚至没有）。

解决：**刷新一次页面（Ctrl+R）**。安装、更新、换素材之后都要刷新。

（实测：改文件、开关插件、改 profile 清单都不会触发前端重载；HMR 只对开发模式的包生效。）

## 七、睡衣版的鞋

睡衣形象穿**纯白袜子**（不是球鞋）。三帧（待机/闭眼/打字）统一处理：
按"裤脚边界"自动定位鞋的区域，只把鞋身压平成白色并保留外轮廓，
所以裤腿不会被误刷白——第一版就是直接按比例切，把裤腿也刷成了白色，退回重做了。
